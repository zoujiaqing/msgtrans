# MsgTrans

MsgTrans — бібліотека Rust для двостороннього обміну повідомленнями в застосунках реального часу. Спільний API підтримує односторонні повідомлення, запити й відповіді через TCP, WebSocket або QUIC. Зміна транспорту не потребує переписування логіки застосунку. Типові сценарії — чати, онлайн-ігри, телеметрія та обмін даними між сервісами.

## Вибір транспорту

| Транспорт | Коли використовувати |
|---|---|
| TCP | Прямі з’єднання нативних клієнтів і зв’язок між сервісами. За потреби можна ввімкнути TLS. |
| WebSocket | Браузери й HTTP-шлюзи з підтримкою переходу на WebSocket. У робочому середовищі використовуйте WSS. |
| QUIC | Нативні клієнти в мережах із мінливою якістю зв’язку, де доступний UDP. Якщо обидві сторони узгодили `msgtrans/2`, сервер може надіслати дані першим без додаткового обміну на рівні застосунку. |

## Що нового у версії 2.0

- **Керування потоком для кожного з’єднання.** Обмежені черги стримують накопичення повідомлень, коли інша сторона працює повільно.
- **Запити прив’язані до з’єднання.** Запізніла відповідь зі старого з’єднання не може завершити запит у новому. Серверний `Responder` можна використати лише один раз.
- **Підтвердження запису не означає доставку.** Воно свідчить, що локальний транспорт прийняв дані, а не що інша сторона отримала або обробила їх.
- **Завершення роботи з перевіркою.** `shutdown()` повідомляє, чи припинили роботу всі слухачі та сеанси в межах відведеного часу.

## Швидкий старт із Rust

Потрібен Rust 1.88 або новіший.

```toml
[dependencies]
msgtrans = "2.0.0"
```

У корені репозиторію запустіть ехо-сервер, а в іншому терміналі — TCP-клієнт:

```sh
cargo run -p msgtrans --example echo_server
```

```sh
cargo run -p msgtrans --example echo_client_tcp
```

[Повний посібник із Rust](README.md) · [Довідник API](https://docs.rs/msgtrans)

## Нативні прив’язки для Kotlin і Swift

[`msgtrans-ffi`](crates/msgtrans-ffi/README.md) через UniFFI надає **клієнтський API** для Kotlin (Android, JVM, Kotlin Multiplatform) і Swift (iOS, macOS). Підтримуються TCP (зокрема TLS), WebSocket і QUIC, а також відповіді на запити, ініційовані сервером. Серверний API доступний у бібліотеці Rust. FFI постачається як нативні бібліотеки зі згенерованими прив’язками, а не як окремий пакет на crates.io. Для браузерів є окремий [клієнт WebSocket на TypeScript](https://github.com/zoujiaqing/msgtrans-typescript).

[Посібник з міграції](docs/MIGRATION_2.0.md) · [Формат пакетів](docs/WIRE_FORMAT.md). Формат пакетів не змінився, але змінилися API Rust і правила встановлення з’єднань. Суворе декодування ввімкнено за замовчуванням. QUIC-вузли, які не пропонують ALPN, зокрема MsgTrans 1.0.10, не підтримуються.

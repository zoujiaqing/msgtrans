# MsgTrans

MsgTrans مكتبة بلغة Rust لتبادل الرسائل في الاتجاهين ضمن تطبيقات الزمن الفعلي. تتيح واجهة برمجية موحّدة إرسال رسائل أحادية الاتجاه وتبادل الطلبات والردود عبر TCP أو WebSocket أو QUIC، من دون إعادة كتابة منطق التطبيق عند تبديل وسيلة النقل. وهي مناسبة للمحادثات والألعاب عبر الإنترنت والقياس عن بُعد والتواصل بين الخدمات.

## اختيار وسيلة النقل

| وسيلة النقل | حالات الاستخدام |
|---|---|
| TCP | اتصالات مباشرة للعملاء الأصليين أو بين الخدمات، مع إمكانية استخدام TLS عند الحاجة. |
| WebSocket | المتصفحات وبوابات HTTP التي تدعم الترقية إلى WebSocket. استخدم WSS في بيئة الإنتاج. |
| QUIC | العملاء الأصليون على شبكات تتغيّر جودة اتصالها وتسمح باستخدام UDP. عند اتفاق الطرفين على `msgtrans/2`، يستطيع الخادم الإرسال أولًا من دون جولة إضافية على مستوى التطبيق. |

## الجديد في الإصدار 2.0

- **التحكم في التدفق لكل اتصال:** تحدّ قوائم الانتظار محدودة السعة من تراكم الرسائل عندما يتباطأ الطرف الآخر.
- **ربط الطلبات باتصالها الأصلي:** لا يمكن لردّ متأخر من اتصال سابق إكمال طلب على الاتصال الجديد. يُستخدم `Responder` على الخادم مرة واحدة فقط.
- **تأكيد الكتابة ليس تأكيدًا للتسليم:** يعني أن طبقة النقل المحلية قبلت البيانات، ولا يضمن أن الطرف الآخر استلمها أو عالجها.
- **إيقاف يمكن التحقق منه:** تُبلغ الدالة `shutdown()` عمّا إذا كانت منافذ الاستماع وجلسات الخادم قد توقفت ضمن المهلة.

## البدء باستخدام Rust

يلزم Rust بالإصدار 1.88 أو أحدث.

```toml
[dependencies]
msgtrans = "2.0.0"
```

من المجلد الجذر للمستودع، شغّل خادم الصدى، ثم شغّل عميل TCP في نافذة طرفية أخرى:

```sh
cargo run -p msgtrans --example echo_server
```

```sh
cargo run -p msgtrans --example echo_client_tcp
```

[دليل Rust الكامل](README.md) · [مرجع الواجهة البرمجية](https://docs.rs/msgtrans)

## الربط الأصلي مع Kotlin وSwift

توفّر [`msgtrans-ffi`](crates/msgtrans-ffi/README.md) **واجهة العميل** عبر UniFFI للغة Kotlin على Android وJVM وKotlin Multiplatform، وللغة Swift على iOS وmacOS. تدعم TCP (بما في ذلك TLS) وWebSocket وQUIC، ويمكنها الردّ على الطلبات التي يبدأها الخادم. تبقى واجهة الخادم في مكتبة Rust فقط. تُوزّع FFI على شكل مكتبات أصلية مع شيفرة الربط المُولّدة، وليس كحزمة مستقلة على crates.io. وللمتصفحات، يتوفّر [عميل WebSocket منفصل بلغة TypeScript](https://github.com/zoujiaqing/msgtrans-typescript).

## الترقية من الإصدار 1.x

[دليل الترحيل](docs/MIGRATION_2.0.md) · [تنسيق الحزم](docs/WIRE_FORMAT.md). لم يتغيّر تنسيق الحزم، لكن واجهة Rust وقواعد الاتصال تغيّرت. فك الترميز الصارم هو السلوك الافتراضي. لا تُدعم أطراف QUIC التي لا تعلن عن ALPN، ومنها MsgTrans 1.0.10.

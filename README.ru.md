# MsgTrans

[English](README.md) | [简体中文](README.zh-Hans.md) | [繁體中文](README.zh-Hant.md) | [Français](README.fr-FR.md) | [Deutsch](README.de.md) | [Español](README.es.md) | [Українська](README.uk.md) | **Русский** | [日本語](README.ja-JP.md) | [한국어](README.ko-KR.md) | [Tiếng Việt](README.vi-VN.md)

MsgTrans — библиотека Rust для двустороннего обмена сообщениями в приложениях реального времени. Единый API поддерживает односторонние сообщения, запросы и ответы через TCP, WebSocket или QUIC. При смене транспорта не нужно переписывать логику приложения. Типичные сценарии — чаты, онлайн-игры, телеметрия и обмен данными между сервисами.

## Выбор транспорта

| Транспорт | Когда использовать |
|---|---|
| TCP | Прямые соединения нативных клиентов и обмен данными между сервисами. При необходимости можно включить TLS. |
| WebSocket | Браузеры и HTTP-шлюзы с поддержкой переключения на WebSocket. В рабочей среде используйте WSS. |
| QUIC | Нативные клиенты в сетях с меняющимся качеством связи, где доступен UDP. Если обе стороны согласовали `msgtrans/2`, сервер может отправить данные первым без дополнительного обмена на уровне приложения. |

## Что нового в 2.0

- **Управление потоком для каждого соединения.** Очереди ограничены, поэтому сообщения не могут бесконечно накапливаться при замедлении другой стороны.
- **Запросы привязаны к соединению.** Запоздалый ответ из старого соединения не может завершить запрос в новом. Серверный `Responder` можно использовать только один раз.
- **Подтверждение записи не означает доставку.** Оно означает, что данные принял локальный транспорт, а не что их получила или обработала другая сторона.
- **Проверяемое завершение работы.** `shutdown()` сообщает, остановились ли слушатели и сеансы в отведённый срок.

## Быстрый старт с Rust

Требуется Rust 1.88 или новее.

```toml
[dependencies]
msgtrans = "2.0.0"
```

Из корня репозитория запустите эхо-сервер, а в другом терминале — TCP-клиент:

```sh
cargo run -p msgtrans --example echo_server
```

```sh
cargo run -p msgtrans --example echo_client_tcp
```

[Полное руководство по Rust](README.md) · [Справочник API](https://docs.rs/msgtrans)

## Нативные привязки для Kotlin и Swift

[`msgtrans-ffi`](crates/msgtrans-ffi/README.md) предоставляет **клиентский API** через UniFFI для Kotlin (Android, JVM, Kotlin Multiplatform) и Swift (iOS, macOS). Поддерживаются TCP (включая TLS), WebSocket и QUIC, в том числе ответы на запросы, инициированные сервером. Серверный API доступен в библиотеке Rust. FFI распространяется в виде нативных библиотек и сгенерированных привязок, а не отдельного пакета на crates.io. Для браузеров есть отдельный [клиент WebSocket на TypeScript](https://github.com/zoujiaqing/msgtrans-typescript).

## Обновление с 1.x

[Руководство по миграции](docs/MIGRATION_2.0.md) · [Формат пакетов](docs/WIRE_FORMAT.md). Формат пакетов не изменился, но изменились API Rust и правила установки соединений. По умолчанию используется строгое декодирование. QUIC-узлы, не предлагающие ALPN, включая MsgTrans 1.0.10, не поддерживаются.
